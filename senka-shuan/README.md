# 専科週案ツクール

専科の先生用の週案作成ツール（「週案ツクール v8.8」と同じ形式の、1つのHTMLファイル）。

- 使うファイル：`専科週案ツクール.html`（ダブルクリックで開き、「保存」で同じファイルに上書き）
- 作り方：`template.html` を直したら `python3 build.py` を実行（`presets.json` の教科書の年間指導計画を入れて `専科週案ツクール.html` を作る）

## 週案ツクールとのちがい

- 時間割のマスには教科ではなく **担当クラス**（4-1 など）を入れる。「会議」「空き」などの予定も入れられる（時数に数えない）
- 単元計画は **学年×教科** ごと（同じ学年のクラスで共通）。進み方はクラスごとに数える
- コマにクラスを入れると、そのクラスの **前の続きの単元・時** が自動で入る。「この週に単元の続きを入れる」でまとめて入る
- 時数は **クラスごと** に集計（標準時数・達成率・過不足）。週案の横に「進み具合」の表
- 印刷（B5縦）の時数表もクラスごと
- 教科は算数・図工・音楽・家庭。教科書の計画：
  - 算数（学校図書）1〜6年、図工（日本文教出版）1〜6年、音楽（教育芸術社）1〜6年、家庭（東京書籍）5・6年
  - 音楽・図工3〜6年・家庭は `tools/` のスクリプトで、各社が公開している年間指導計画の資料から作った
    - 音楽：教育芸術社「指導計画案（主な学習の流れと題材の評価規準例）」Excel → `tools/ongaku.py`
    - 図工：日本文教出版「年間指導計画・評価規準例」Excel → `tools/zuko.py`
    - 家庭：東京書籍「年間指導計画作成資料」Word → `tools/katei.py`
- 組の名前（例：松、竹、梅、月）を設定すると、その順番でクラスが並ぶ。全学年の組名を一括で変えられる
