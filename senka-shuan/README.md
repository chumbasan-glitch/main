# スマート専科用週案

専科の先生用の週案作成ツール（「週案ツクール v8.8」と同じ形式の、1つのHTMLファイル）。

- 使うファイル（ダブルクリックで開き、「保存」で同じファイルに上書き）
  - 来年度用：`スマート専科用週案.html`（v2系。元のコードは `template.html`）
  - 今年度用：`スマート専科用週案_v1.7_今年度用.html`（v1.6 に、v2.1 と同じ保存のしかただけを足したもの。元のコードは `kotoshi/template.html`）
- v2.0：スマート週案簿 v10.1 の機能を取り入れた（週案シート6種類・印刷の形・年度のとちゅうからの時間割・来週ボタン・印刷のしかた・入力や保存の安定化など）
- v2.1：スマート週案簿 v10.2・v10.3 の「保存を強くする」を取り入れた（自動保存・保存した内容の読み返し・保存のテスト・バックアップのおすすめ・保存の表示の色）
- v2.2：行事予定のタブ（カレンダーで行事・休み・土曜授業を入れる）。担当している学年と全学年の行事が、週案の「行事」（朝・中休み・昼休みを選んだものはその欄にも）に入る。授業のコマは変えない。「行事予定ファイル」の書き出し・取り込みで、スマート週案簿（v10.9〜）とやりとりできる
  - テスト：`NODE_PATH=$(npm root -g) node tools/tests/events.js <画像を置くフォルダ>`（スマート週案簿で書き出す→専科用で取り込む→専科用で書き出す→スマート週案簿で取り込む）
- 保存の名前：はじめて保存するときだけ「音楽専科週案2026.10.19～」。そのあとは開いているファイルに上書き
- 印刷（PDF）のファイル名は「音楽専科週案2026.10.19～」（専科名＋週案＋開いている週の月曜日）
- 作り方：`template.html` か `kotoshi/template.html` を直したら `python3 build.py` を実行（`presets.json` の教科書の年間指導計画を入れて、上の2つのファイルを作る）

## 週案ツクールとのちがい

- 時間割のマスには教科ではなく **担当クラス**（4-1 など）を入れる。「会議」「空き」などの予定も入れられる（時数に数えない）
- 単元計画は **学年×教科** ごと（同じ学年のクラスで共通）。進み方はクラスごとに数える
- コマにクラスを入れると、そのクラスの **前の続きの単元・時** が自動で入る。「この週に単元の続きを入れる」でまとめて入る
- 時数は **クラスごと** に集計（標準時数・達成率・過不足）。週案の横に「進み具合」の表
- 印刷（B5縦）の時数表もクラスごと
- 教科は算数・図工・音楽・家庭。教科書の計画：
  - 算数（学校図書）1〜6年、図工（日本文教出版）1〜6年、音楽（教育芸術社）1〜6年、家庭（東京書籍）5・6年
  - 音楽・図工3〜6年・家庭は `tools/` のスクリプトで、各社が公開している年間指導計画の資料から作った
    - 音楽：教育芸術社「指導計画案（主な学習の流れと題材の評価規準例）」Excel → `tools/ongaku.py`
    - 図工：日本文教出版「年間指導計画・評価規準例」Excel → `tools/zuko.py`
    - 家庭：東京書籍「年間指導計画作成資料」Word → `tools/katei.py`
- 組の名前（例：松、竹、梅、月）を設定すると、その順番でクラスが並ぶ。全学年の組名を一括で変えられる
