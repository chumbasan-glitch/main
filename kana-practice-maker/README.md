# ひらがな・カタカナ れんしゅうプリント（1年生むけ）

## つかいかた
1. **`kana-practice.html`** をダウンロードして、パソコンや iPad に保存します。
2. ファイルを開くと（Edge・Chrome・Safari）、そのまま使えます。**ネットにつながっていなくても動きます。**
3. 左がわで ①〜⑦ を えらぶと、右がわに プリントが できます。
4. 「いんさつする」を押します。いんさつの画面では、
   - 用紙サイズ：画面に出ている サイズ（B5・A4・B4）
   - 向き：縦 または 横
   - 倍率：100%（実際のサイズ）

   になっているか たしかめてください。

## できること
- ひらがな／カタカナ（清音・濁音・半濁音・拗音・っ・ー）から、いくつでも字をえらべる
- もんだいの形：A なぞりがき／B うつしがき／C ことばの なぞり・うつし／D あなあき ことば
- かきじゅん（1画ずつ ふえていく図）を 入れる・入れない
- ならべかた（字ごと・かたちごと）、たてがき・よこがき、紙のたて長・よこ長、マスの大きさ
- もんだいの数に合わせて、B5・A4・B4 から いちばん小さい紙を おすすめ（B4に入りきらない数は えらべません）
- ことばの きめかた：ランダム／いつも同じ／先生がえらぶ
- ことばリストに 足す・けす（ファイルに保存して、ほかのパソコンや iPad で よみこめます）
- タイトル・めあてを 書きかえ、こたえのページ（D の こたえを赤字で）

## メモ（作る人むけ）
- `template.html` を直したら `python3 build.py` で `kana-practice.html` を作りなおします。
- ことばは `words-hiragana.txt`・`words-katakana.txt`（ことば・タブ・えもじ）。
- かきじゅんの図：KanjiVG（© Ulrich Apel, CC BY-SA 3.0）から `strokes.json` を作っています。
- 書体：Windowsは「UD デジタル 教科書体」。入っていない端末（iPadなど）用に Klee One（SIL Open Font License, `KleeOne-OFL.txt`）の かなだけを うめこんでいます。
