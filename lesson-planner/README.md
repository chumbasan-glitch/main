# 授業プランノート

小学校の単元計画・本時の流れ（細案）・板書計画・振り返りシート・パフォーマンス課題を、表示・修正・保存・印刷するためのツールです。

- `lesson-planner.html` をダブルクリックして開きます（Edge / Chrome）。インターネット接続は不要です。
- プランの中身は Claude のチャットで作ります。ツールの「＋ 新しい単元」で依頼文をコピーしてチャットに貼り付け、受け取ったプランのファイル（.json）を「ファイルを開く」で開きます。
- 「保存」で OneDrive に保存しておけば、次からは同じプランをいつでも開けます。
- iPad では、「印刷・PDF」で作った PDF や「Wordで書き出し」で作った Word ファイルを OneDrive に置いて使います。
