# まいにち授業ノート

6年生の国語・算数・理科・社会の「毎日の授業案」「授業後の振り返り（板書の写真つき）」「進み具合」をまとめるツール（iPadのSafari用、1つのHTMLファイル）。

- 使うファイル：`まいにち授業ノート.html`
- 授業案と振り返りは、ツールがコピーする「お願いの文」をClaudeのアプリに貼り付けて作り、答えをツールに貼り戻す
- 記録はiPadの中（Safariの保存場所）だけにしまう。写真も同じ。「記録・バックアップ」でファイルに保存できる
- 単元の一覧（`units6.json`）は「スマート週案簿 v9.4」に入っている年間指導計画から取り出したもの
  - 国語：光村図書、算数・理科：学校図書、社会：東京書籍
- 作り方：`template.html` を直したら `python3 build.py` を実行
