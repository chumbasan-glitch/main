# 算プリツクール 更新のきろく

- 4.1　立体の体積の図：奥行きは右下の辺に，高さは矢印つきの線で示す，凹・十字・円柱の一部・水そうの数字を見やすく／円の面積（色をぬった部分）の半径の数字を線や円に重ならないように
- 4.0　文章題で同じ場面の問題がとなりあわないようにし，場面の少ない問題に場面を追加／細かい内容ごとに問題数を決められるように
- 3.9　立体の見取図で、長さの数字が線や図形・ほかの数字に重ならない場所を自動でさがして書く（上・右の辺は奥の辺に書く）
- 3.8　計算して求める図の問題（面積・角度・円周・体積など）をすべて「式」「答え（　）」の形にし、答えのプリントに式を出す／水そうの側面にも色／穴のあいた円柱に寸法線
- 3.7　立体の体積：チャレンジに水の問題を追加、図の問題を「式」「答え（　）」の形に、長さの数字を図から少しはなす
- 3.6　立体の体積に、立てた角柱・十字の形・単位をそろえる円柱（こう貨・ぼう）などを追加し、見えない線を正しくかく
- 3.5　6年「立体の体積」を、見取図の長さから底面積を求める問題に作り直す（くふうして求める・およその体積を追加）
- 3.4　名前を「算プリツクール」に変更
- 3.3　6年「分数倍」のきほんを、約分しなくてよい小さな分数にする
- 3.2　小数と分数がまじる計算の答えに、仮分数（帯分数，小数）を出す
- 3.1　印刷・保存の近くと印刷用の画像の画面に注意書きを追加
- 3.0　入試の場合の数（カード・硬貨・図形）、数の性質、表面積の問題をふやす
