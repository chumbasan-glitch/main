# 時間割作成ツール　使い方

このツールには2つの版があります。どちらも、質問の内容と時間割の組み方は同じです。

| | HTML版 | GAS版（Googleスプレッドシート） |
|---|---|---|
| 始め方 | `時間割作成ツール_v〇.html`（〇はバージョン） をダブルクリックするだけ | 下の「設定手順」（約20分） |
| 答えの保存 | そのパソコンのブラウザ（ファイルにも保存できる） | スプレッドシート |
| 時間割の出力 | 画面で手直し・印刷（A3横）・Excelで開けるファイル | スプレッドシート・A3のPDF |
| ほかの先生と共有 | 答えのファイルを渡す | スプレッドシートを共有する |

---

## HTML版の使い方

1. `時間割作成ツール_v〇.html`（〇はバージョン） を、Chrome または Edge で開きます（ダブルクリック）。
2. 「はじめる」を押し、質問に1つずつ答えます。答えはこのパソコンのブラウザに自動で保存されます。
3. 最後の「時間割を作る」を押すと、時間割ができます。
4. 時間割のマスはクリックすると直接書きかえられます。直したら「手直しした時間割をチェックする」を押してください。
5. 「印刷する（A3横）」で印刷します。印刷の画面で「PDFに保存」を選ぶと、PDFにもできます。
   用紙サイズはA3・横、余白は「なし」か「最小」にしてください。
6. 「Excelで開けるファイルに保存」で、ダウンロードフォルダに `.xls` のファイルができます。
   Excelで開くときに「ファイル形式と拡張子が一致しません」と出たら「はい」を押してください。

### 答えのファイル
- 最後のページの「答えをファイルに保存」で、`〜_答え.json` というファイルができます。
- ほかのパソコンや来年度は、最初のページの「ファイルから読み込む」でこのファイルを選んでください。
- ブラウザの履歴やサイトのデータを消すと、ブラウザに保存した答えも消えます。ときどきファイルにも保存してください。

## GAS版（Googleスプレッドシート）の設定手順

最初に一度だけ行う作業です。20分ほどかかります。プログラムの知識は必要ありません。
学校のGoogleアカウントでログインしてから始めてください。

---

## 1. スプレッドシートを作る

1. Googleドライブを開き、「新規」→「Googleスプレッドシート」で新しいスプレッドシートを作ります。
2. 左上の「無題のスプレッドシート」を「時間割作成ツール」などの名前に変えます。

## 2. プログラムを貼りつける

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開きます。
2. 左の「ファイル」に `コード.gs` があります。中身をすべて消して、`Code.gs` の中身をすべて貼りつけます。
3. 「ファイル」の横の「＋」→「HTML」を選び、名前を `Index` にします（「.html」は自動でつきます）。中身をすべて消して、`Index.html` の中身を貼りつけます。
4. 同じようにHTMLファイルを2つ作ります。
   - 名前 `Logic` … `Logic.html` の中身を貼りつける
   - 名前 `Check` … `Check.html` の中身を貼りつける
5. 上の保存ボタン（フロッピーの形）を押します。

ファイル名は **Index・Logic・Check**（大文字・小文字も同じ）にしてください。ちがう名前だと動きません。

## 3. 公開する（Webアプリにする）

1. Apps Scriptの右上「デプロイ」→「新しいデプロイ」を押します。
2. 「種類の選択」の歯車 → 「ウェブアプリ」を選びます。
3. 次のように設定します。
   - 説明：時間割作成ツール（なんでもよい）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**（ほかの先生も使う場合は「（学校名）内の全員」）
4. 「デプロイ」を押します。
5. 「アクセスを承認」→ 自分のアカウントを選ぶ → 「詳細」→「（安全ではないページ）に移動」→「許可」と進みます。
   自分で作ったプログラムなので、この画面が出るのは正常です。
6. 表示された「ウェブアプリのURL」を開くと、入力画面が出ます。このURLをブックマークしておきます。

## 4. 使い方

1. 入力画面で「はじめる」を押し、質問に1つずつ答えます。「保存して次へ」を押すたびに、答えがスプレッドシートの「保存データ」シートに保存されます。
2. 最後の「時間割を作る」を押すと、自動で組みます（1〜2分かかることがあります）。
3. 「スプレッドシートに書き出す」を押すと、「時間割一覧」シートに出ます。
   - 上：全クラスの時間割
   - 下：専科・講師の先生の担当と、特別教室の割り当て
4. 「A3のPDFを作る」を押すと、A3横1枚のPDFがマイドライブにできます。

### 手で直したあと

「時間割一覧」シートで授業を入れかえたら、スプレッドシートのメニュー「時間割ツール」→「時間割をチェックする」を押します（入力画面の最後のページにも同じボタンがあります）。

- 時数のずれ、特別教室の上限オーバー、専科の先生の重なりなどを表示します。結果は「チェック結果」シートにも出ます。
- 専科・講師の先生の行（下の表）も直すと、その先生の重なりもチェックします。
- 下の「特別教室」の表は、上の表から自動で作り直します。

メニュー「時間割ツール」は、スプレッドシートを開き直すと表示されます。

### 次の年度

入力画面の最初のページで「新しく作る」の名前を次の年度にし、「最初の答え」で前年度を選びます。変わったところだけ直せば使えます。

## こまったとき

| こまったこと | 直し方 |
|---|---|
| 「入らなかったコマ」が出る | 時間割の黄色いマスが空きです。手で入れてからチェックしてください。「もう一度組む」を押すと別の組み方を試します。 |
| 最後のページに赤い注意が出る | 時数と使えるコマ数が合っていない、教室の上限が足りない、などです。書いてある質問にもどって直してください。 |
| プログラムを直したのに画面が変わらない | 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」を押してください。 |
| メニュー「時間割ツール」が出ない | スプレッドシートを開き直してください。 |
